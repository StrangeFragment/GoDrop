# GoDrop!

Программа для Windows, которая живёт в системном трее и позволяет
передавать фотографии и файлы с телефона на компьютер через локальную сеть.

Запустили → в трее появился значок → навели телефон на QR-код → выбрали файлы
→ на компьютере они оказались в папке `Downloads\GoDrop\<дата>\`.

## Как это работает

1. При запуске поднимается HTTP-сервер на порту из настроек (по умолчанию 777;
   если порт занят — берётся 666, 777, 888, 999 или любой свободный).
2. Значок в трее показывает адрес вида `http://192.168.1.10:777`.
3. Телефон (в той же Wi-Fi сети) открывает этот адрес, выбирает файлы
   и отправляет их.
4. Файлы сохраняются в папку `хранилище\<ГГГГ-ММ-ДД>\`. Имена не затираются:
   второй `photo.jpg` сохранится как `photo (1).jpg`.

Меню значка:

| Пункт | Что делает |
| --- | --- |
| **GoDrop!** (и левый клик по значку) | показывает окно с QR-кодом |
| **Хранилище** | открывает папку с принятыми файлами |
| **Настройки** | папка хранения, порт, разрешённые расширения, автозапуск |
| **Выход** | останавливает сервер и закрывает открытые окна |

## Сборка

Нужен Go 1.24+ (проект использует Fyne 2.8 и `github.com/gogpu/systray`).

```powershell
# без консольного окна (обычная сборка «для пользователя»)
go build -trimpath -ldflags "-H windowsgui -s -w" -o GoDrop.exe .
```

Если сборка падает из-за cgo/OpenGL, поставьте MSYS2/MinGW-w64 (`gcc`)
и включите `CGO_ENABLED=1`.

Чтобы значок был виден на самом `GoDrop.exe` в Проводнике, добавьте ресурс:

```powershell
go install github.com/akavel/rsrc@latest
rsrc -ico tray/godrop.ico -o rsrc_windows_amd64.syso
go build -ldflags "-H windowsgui -s -w" -o GoDrop.exe .
```

Запуск/остановка автозапуска проверяется в настройках — программа пишет
себя в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (права
администратора не нужны).

## Где лежат файлы

* настройки и логи: `%AppData%\GoDrop\` (`config.json`, `logs\godrop-<дата>.log`);
* принятые файлы: папка из настроек, по умолчанию `%UserProfile%\Downloads\GoDrop`.

Логи старше 14 дней удаляются автоматически при запуске.

## Значок

Все значки программы (трей, окна, favicon и манифест для телефона)
сделаны из одного исходника: `tray/godrop.ico`, `assets/godrop_*.png`,
`web/favicon.ico`, `web/icon-*.png`, `web/apple-touch-icon.png`.

## Скрипты режимов

Программа сама запускает себя с параметрами — вручную они не нужны:

* `GoDrop.exe --qr <файл>` — окно с QR-кодом;
* `GoDrop.exe --settings <файл>` — окно настроек.
