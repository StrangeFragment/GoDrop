GoDrop!

Программа для Windows, которая работает в системном трее и позволяет передавать фотографии и файлы с телефона на компьютер через локальную сеть.

    Можно выбрать несколько файлов сразу. Лимит одной отправки — {{.MaxFileSize}}.
